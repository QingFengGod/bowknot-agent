## 4. 实施总结

- 交付：三态主题、失焦灰灯、托盘与关闭到托盘、单实例、退出放行、macOS 全屏分支。
- 自检：`gofmt -l .` 无输出，`go vet ./...`、`go test ./...` 通过，`go tool mygo build` 成功。
- 关键处理：`App.Quit()` 会触发 `OnClose`，用 `OnBeforeQuit` 的 `quitting` 标记放行，避免托盘「退出」被自身拦截；托盘创建失败则不注册关闭拦截，关闭即退出。
