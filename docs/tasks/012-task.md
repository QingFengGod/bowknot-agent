## 1. 简介

为每个 Agent 建立独立记忆：周文件、`summary.json` 索引、每次对话开始检查日期、跨周生成上一周摘要、检索与提示注入、查看/编辑/删除/导出。不做跨 Agent 共享、P1 冲突处理与新的存储后端。

## 2. 任务拆分

| 编号 | 小任务 | 状态 |
| --- | --- | --- |
| T1 | `internal/memory/store.go`：周文件命名、`summary.json` schema、加载/保存、原子写与损坏回退；单测 | 完成 |
| T2 | 日期触发：周边界计算、当周文件创建、上一周标记待摘要；时钟注入与单测 | 完成 |
| T3 | 摘要生成：网关调用、摘要解析、失败重试且不阻塞对话；替身网关单测 | 完成 |
| T4 | 检索与注入：周索引与关键词检索、网关支持时语义检索、上下文预算与截断；单测 | 完成 |
| T5 | 页面接入：助手与 Agent 对话开始调用日期检查；Agent 页记忆查看、编辑、删除、搜索、导出与清除确认；页面测试 | 完成 |

## 3. 实施顺序

`T1 → T2 → T3 → T4 → T5`

存储契约先定；日期触发依赖周文件；摘要生成依赖触发状态；检索注入依赖索引；页面接入最后做。

## 4. 实施总结

### 产出

- 新增 `internal/memory`：`memory.go`（周命名、`WeekRange`、`WeekBody`、索引与报告类型）、`store.go`（`Ensure` 日期检查、索引加载/保存、临时文件原子替换、损坏索引保留为 `summary.json.corrupt` 后重建、查看/编辑/删除/清除/导出）、`summary.go`（网关摘要、失败保留待重试、空周跳过、摘要清洗与长度上限）、`search.go`（关键词检索、`EmbedFunc` 语义检索与失败降级、按周去重的命中、上下文预算拼装与截断标注）。
- `internal/agent`：`Registry.Memory(id)` 按 Agent 复用记忆存储；新增 `memory.go` 提供摘要/嵌入网关适配、`agentMemoryPrompt`（先装配工作区提示，再注入记忆段，待摘要周在后台生成，不阻塞对话）、Agent 页记忆面板（查看周列表与摘要状态、编辑保存、搜索命中来源、单周删除与全部清除二次确认、导出到工作区并回显路径）；助手与 Agent 的发送、重新生成均以当前输入或最近一条用户消息触发日期检查与检索。
- 记忆落盘于 `agents/<id>/memories/`，目录名、文件权限与原子写对齐现有 `internal/agent` 工作区约定。

### 自检

- `go build ./...`、`go vet ./...`、`go test ./...` 通过；`gofmt -l .` 无输出。
- 新增单测覆盖周边界与命名校验、当周创建与幂等、上一周待摘要、编辑回写待摘要、损坏索引回退、删除/清除/导出、摘要成功与失败重试、空周跳过、关键词与语义检索及降级、上下文预算截断；`internal/agent` 覆盖发送时日期检查与提示注入、后台摘要落地、记忆面板操作与导出。

### 偏差

- FR-MEM-03 的「先生成上一周摘要再创建当周文件」按非阻塞要求实现为：日期检查一次完成（创建当周文件并将上一周标记待摘要），摘要随后在后台生成并写回索引；失败仍保持待摘要供下次重试。
- 提示注入中的「相关记忆片段」使用关键词命中，面板搜索在网关支持向量时走语义检索；注入阶段同步取向量会阻塞界面，故不采用。
- 清除与导出在 Agent 页记忆面板内完成；导出文件落在该 Agent 工作区（`memory-export-<时间>.md`），未引入系统文件选择对话框。

### 遗留

- FR-MEM-04 的自动写入（记住、纠正、任务结论）依赖 013 的 `memory` 工具，本计划只提供存储、索引、摘要、检索与管理。
- FR-MEM-05 的“界面标注引用来源”仅在提示与面板搜索中标注周文件，消息流内引用徽标待后续 UI 计划。
- FR-MEM-08 的隐私中心展示 embedding 供应商与用途归 014/隐私计划。
- FR-MEM-09 的冲突处理为 P1，未实施。
- 周摘要的实际生成质量与记忆面板外观需用户按真机验收。
