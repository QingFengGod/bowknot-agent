## 1. 简介

为每个 Agent 建立独立记忆：周文件、`summary.json` 索引、每次对话开始检查日期、跨周生成上一周摘要、检索与提示注入、查看/编辑/删除/导出。不做跨 Agent 共享、P1 冲突处理与新的存储后端。

## 2. 任务拆分

| 编号 | 小任务 | 状态 |
| --- | --- | --- |
| T1 | `internal/memory/store.go`：周文件命名、`summary.json` schema、加载/保存、原子写与损坏回退；单测 | 草稿 |
| T2 | 日期触发：周边界计算、当周文件创建、上一周标记待摘要；时钟注入与单测 | 草稿 |
| T3 | 摘要生成：网关调用、摘要解析、失败重试且不阻塞对话；替身网关单测 | 草稿 |
| T4 | 检索与注入：周索引与关键词检索、网关支持时语义检索、上下文预算与截断；单测 | 草稿 |
| T5 | 页面接入：助手与 Agent 对话开始调用日期检查；Agent 页记忆查看、编辑、删除、搜索、导出与清除确认；页面测试 | 草稿 |

## 3. 实施顺序

`T1 → T2 → T3 → T4 → T5`

存储契约先定；日期触发依赖周文件；摘要生成依赖触发状态；检索注入依赖索引；页面接入最后做。
