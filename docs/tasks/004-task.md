## 1. 简介

把左侧导航与「应用」模块做成可用骨架：侧栏底部常驻网关状态、当前模型与用量入口；助手 / 创作在网关不可用时显示禁用原因；应用模块提供「已安装」启动器（读本地注册表）与「发现」商店（内置示例、搜索、分类、详情）；切模块保留逻辑状态。不做真实网关、安装 / 卸载 / 启动、图标渲染与滚动位置保留。

## 3. 实施顺序

`T1 → T2 → T3 → T4 → T5 → T6 → T7 → T8 → T9 → T10`

先定数据契约与纯逻辑（T2 状态色、T3 目录与筛选、T5 注册表契约），再做视图（T4 商店、T6 启动器），最后装配壳与 `app`（T7、T8）。侧栏状态位波及 shell 布局，与商店页一起做视图回归成本最低。
