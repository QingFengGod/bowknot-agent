## 1. 简介

在 Run 领域模型上实现群消息存储与总线、子 Agent 多步工具调用、进展/请求/等待/交接/阻塞、汇报与主 Agent 汇总，并把助手与群聊接到新 Run 引擎。任务中心切换与群聊界面放到 016。

## 2. 任务拆分

| 编号 | 小任务 | 状态 |
| --- | --- | --- |
| T1 | `internal/group/message.go`：消息类型、`messages.jsonl` 追加、顺序、上限与可见性；单测 | 草稿 |
| T2 | `internal/group/bus.go`：广播、定向请求/答复、等待超时、主 Agent 全量可见、无私聊旁路；单测 | 草稿 |
| T3 | 执行器与工具：子 Agent 多步循环（`group.post/request/wait`）、主 Agent `delegate`、步数上限、取消与工具错误；替身模型单测 | 草稿 |
| T4 | Run 编排：就绪任务执行、汇报收集、主 Agent 汇总、失败说明与预算控制；单测 | 草稿 |
| T5 | 接入：助手自动派发创建 Run、群聊 Run 创建、移除任务模式；群 Run 开始时接入记忆日期检查；旧任务中心适配保留到 016；单测 | 草稿 |

## 3. 实施顺序

`T1 → T2 → T3 → T4 → T5`

消息落盘先定；总线依赖消息；执行器依赖总线与插件工具；编排依赖执行器；最后接助手与群聊入口。
