## 1. 简介

实现进程内 AI 网关最小闭环：供应商配置与加密密钥、连接测试、`chat` / `embedding` 调用（含 SSE 与重试回退）、六类能力路由数据、状态快照（接侧栏）、JSONL 用量记录，以及设置模块「模型服务」页。不做助手对话、多 Agent、图片视频语音、费用估算、HTTP 服务与系统凭据库。

## 3. 实施顺序

`T1 → T2 → T3 → T4 → T5 → T6 → T7 → T8 → T9 → T10 → T11 → T12 → T13`

配置契约与加密是纯逻辑且被界面、客户端共同依赖，必须先行（T1、T2）；错误分类与适配器决定可用性判定（T3、T4）；客户端与路由完成核心能力（T5、T6）；门面、快照、用量随后（T7、T8）；设置界面依赖门面稳定，放在最后（T9、T10）；回归修复按验收反馈追加（T13）。

## 4. 实施总结

- 交付：供应商 CRUD、加密密钥与掩码、连接测试、chat / embedding 与流式、路由回退、状态快照、用量文件、设置页。
